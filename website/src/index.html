Native interfaces / Fabric

Build a proper interface. Keep the game.

PaneLib is a client-side Fabric library for building Minecraft screens and gameplay HUDs entirely in Java. It is native and retained: no Chromium, HTML, CSS parser or MCEF. A screen repaints only when something changes, and Minecraft still draws its own items, entities and world.

§01 Rendering model

Paint once, then get out of the way

  1. Paint on changeYour Java painter runs when state, hover, size or invalidate() changes. Finite animations stop scheduling frames when they end.
  2. Reuse the textureThe result is uploaded to one reusable GPU texture and simply blitted while the screen is idle.
  3. Compose native layersItemStacks and entities render through Minecraft in a separate layer, and do not invalidate the retained surface.

This website is documentation only; nothing here runs inside the game.

§02 Your first screen

A document, a page, a screen

Publish the release candidate to Maven Local, then build a UiDocument with one or more UiPage painters and open a UiScreen. A public Maven host has not been selected yet.

./gradlew :pane:publishToMavenLocal
./gradlew runClient

Read the full guide → · Gradle setup

Java
var home = new UiPage("home", "Home", "H", 0xFF58A6FF, ui -> {
    float x = ui.contentX() + 24;
    float y = ui.contentY() + 24;

    ui.canvas().textMedium("Hello, PaneLib", x, y, 24, ui.theme().text());
    ui.button("save-button", "Save", "save",
        x, y + 40, 88, 32,
        UiContext.ButtonStyle.PRIMARY, UiContext.Shape.ROUNDED);
});

var document = UiDocument.builder("My mod")
    .brand("My mod")
    .theme(UiTheme.dark())
    .page(home)
    .build();

var screen = new UiScreen(document, NativeOverlayRenderer.NONE, event -> {
    if (event.type() == UiEventType.ACTION && event.key().equals("save")) saveConfig();
});

Minecraft.getInstance().gui.setScreen(screen);

§03 In the game

Input-free gameplay HUDs

UiHud reuses the same drawing, state and motion APIs for widgets drawn over gameplay. Equal values do not repaint; anchors use logical points; world changes release surfaces. The library installs no key or mouse listeners and never calls setScreen.
