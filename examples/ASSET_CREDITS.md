# Example asset credits

PaneLib's runtime library contains no showcase pictures. These assets belong to the separate
example/demo module; they are not required to make a new interface with PaneLib.

- **Wayfarer background:** Fouriesburg Mountain Lookout, photographed by Dimitrios Savva and
  processed by Jarod Guest, [Poly Haven](https://polyhaven.com/a/fouriesburg_mountain_lookout),
  [CC0](https://polyhaven.com/license). The bundled `textures/wayfarer/mountain-lookout.png`
  is a perspective crop of the photograph. SHA-256:
  `a8b3b97b2b19e9114a255292671c454879f77a81c22f0818123f4c36573db6e2`.
- **Wayfarer explorer skin:** generated artwork converted to a standard classic 64×64 Minecraft
  skin atlas. The final atlas is `textures/wayfarer/explorer-skin.png`. The preview changes only a
  temporary render snapshot; it does not change the player's account skin. Generation references
  and intermediate artwork are not included in the public source snapshot.
- **Paper, leather and wood:** CC0 materials; see
  [Bramble material credits](bramble-hud/materials/LICENSE-AND-SOURCE.md).
- **Wayfarer HUD metal and fabric:** CC0 photography by Rob Tuytel; see
  [HUD material credits](wayfarer-hud/materials/LICENSE-AND-SOURCE.md).
- **Gather and Pane Mail thumbnails:** captures of the fictional local examples built with PaneLib.
  They contain sample data, not connected user accounts or service conversations.
- **Roboto:** the bundled font retains its SIL Open Font License in
  `pane-demo/src/main/resources/assets/pane_demo/fonts/OFL.txt`.

Wayfarer is an interface showcase, not a separate playable game. Material provenance does not
change the license notices shipped with the relevant fonts or source code.
