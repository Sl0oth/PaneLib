# PaneLib 0.9.7 / ServerSurfer audit handoff

## Fixed in PaneLib

- Continuous wheel and trackpad input follows a moving target without restarting easing.
- Virtual rows are rasterized only for the viewport plus bounded overscan and composed from a GPU atlas.
- Every row uses one shared fractional transform, so baselines and separators do not form a wave.
- Tooltip appearance does not move virtual-row text or switch its raster path.
- Moving, reversed, and recycled rows keep their painted hit targets aligned.
- `scrollVirtualItemIntoView(listId, index)` supports consumer-owned arrow selection.
- A warmed list creates no new retained textures, virtual atlases, or row-storage buffers while scrolling.
- Test diagnostics expose paint count, partial paint count, last uploaded pixels, row raster count,
  row-upload pixels, and retained allocation counts.
- Escape-to-parent, explicit close-to-parent, raw keys, true double-clicks, async invalidation,
  backdrop composition, and resize synchronization are public documented APIs.

The real-client harness passed single/double click during motion, double-click after direction
reversal, arrow reveal of row 250, Tab and Shift-Tab, tooltip baseline stability, fractional row
placement, tiny/large resize, 30-second simulated continuous input, and exactly zero repaints over
five idle seconds. The warmed scrolling allocation deltas were all zero. Row raster work was 3.3%
of the legacy complete-surface equivalent in the measured run.

## Intentionally remains in ServerSurfer

These are application correctness concerns and must not become PaneLib policy:

- Dependency and manifest pins: `build.gradle` and `src/main/resources/fabric.mod.json`.
- Stable server keys, dataset generations, prepared strings, selection, row actions, search,
  categories, filters, recents, detail state, paging, and refresh behavior:
  `src/client/kotlin/slooth/browser/screen/PaneServerBrowser.kt`.
- Defensive favicon decoding, request deduplication, and dataset-aware completion callbacks:
  `src/client/kotlin/slooth/browser/ServerImageCache.kt`.
- Defensive ping/favicon parsing, request deduplication, and dataset-aware completion callbacks:
  `src/client/kotlin/slooth/browser/ServerPinger.kt`.
- Source-specific normalization and trusted country/version parsing:
  `src/client/kotlin/slooth/browser/api/`.
- Reproducible ServerSurfer artifact hash and consumer regression report: the ServerSurfer build
  and release workflow.

PaneLib cannot decide whether two server records are the same, whether an async response belongs
to a replaced dataset, or whether join/copy/add semantics are correct. The consumer should attach
those operations to a normalized stable server key, use a monotonically increasing dataset
generation in completion callbacks, and look up the current index only at invalidation time.

## Artifact rule

Old Maven Local version directories are normal immutable cache entries and should not be deleted.
The meaningful checks are that the consumer declares one version, `compileClasspath` resolves that
exact version, and active build/run outputs do not package or load a stale JAR.
