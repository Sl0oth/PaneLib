PaneLib beta.4 is now available for Minecraft 1.20–1.20.1 on Fabric.

- Build settings forms with sliders, toggles, key bindings and a colour picker. PaneLib can save the values and load them again the next time the game starts.
- Drag a HUD into place, fine-tune it with the arrow keys and click its controls while chat is open. Static HUDs keep their texture between frames.
- Draw a player preview from a skin texture, including from the title screen. Item slots use the active resource pack.
- Cursor movement and Backspace keep joined emoji together. Text fields also accept words committed by an input method.

Install Fabric Loader 0.20.1 or newer, Fabric API for your game version, and this JAR. Mods that use PaneLib supply the screens and HUDs.

Tested in Minecraft on Windows, macOS and Linux. Sodium and Iris both passed.

For Sodium 0.5.13 on 1.20.1, use the LWJGL 3.3.1 libraries supplied by the Minecraft launcher.
