# PaneLib beta.4 Fabric backports

Pick the row with your exact Minecraft version. Put its JAR and the matching Fabric API in your client’s `mods` folder. Fabric Loader 0.20.1 or newer is required. The mod that uses PaneLib supplies the screens and HUDs.

For mod developers, download the [standalone starter](https://github.com/Sl0oth/PaneLib/releases/download/v1.0.0-beta.4-fabric-backports/standalone-starter.zip) and follow [the setup guide](full-source-candidates/START-HERE.md). The example checks the library hash and builds a separate mod.

## Build from source

From the repository root, run `./gradlew -p backports -Pmc=1.20.1 test build`. Substitute any version in the table. Install JDK 25 for Gradle and the game JDK listed in the starter. The build applies the target’s patches to the standalone beta.4 sources.
